🏦 Desktop Bank Application (Python + Tkinter + SQLite)

Полноценное десктопное банковское приложение с графическим интерфейсом и реляционной базой данных SQLite.

✨ Возможности
👤 Управление счетами: создание новых счетов с проверкой уникальности имени.
💰 Операции с балансом: пополнение и снятие наличных с валидацией сумм.
🔄 Переводы между счетами: всплывающее модальное окно (Toplevel) для безопасного перевода между клиентами.
📜 История транзакций: детальная выписка всех операций по счёту.
🛡️ Безопасность данных: защита от отрицательного баланса, параметризованные SQL-запросы (?) против SQL-инъекций.
📦 Автономность: приложение компилируется в .exe для запуска без установленного Python.
🛠 Стек технологий
Язык: Python 3.13
База данных: SQLite3 (связи через FOREIGN KEY, каскадное хранение истории)
Интерфейс (GUI): Tkinter (Frame, Toplevel, messagebox)
Сборщик: PyInstaller
